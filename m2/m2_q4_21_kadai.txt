# Pythonの演算子について


## 演算子の優先順位
Pythonでは、複数の演算子がある場合、優先順位の高いものから計算されます。

主な優先順位は次のとおりです。

1. ()：括弧
2. **：累乗
3. +x、-x：正負の符号
4. *、/、//、%：掛け算・割り算など
5. +、-：足し算・引き算
6. ==、!=、<、>、<=、>=：比較演算子
7. not：論理否定
8. and：論理積
9. or：論理和

例えば、次の計算では掛け算が足し算より先に行われます。

```python
result = 2 + 3 * 4
print(result)
```

実行結果：
```text
14
```

括弧を使うと、計算する順番を変更できます。

```python
result = (2 + 3) * 4
print(result)
```

実行結果：
```text
20
```

## 調べて分かったこと
Pythonには、数値を計算する算術演算子だけでなく、条件を比較する比較演算子や、複数の条件を組み合わせる論理演算子があることが分かりました。

また、演算子には優先順位があり、優先順位を理解しておくことで、計算結果を正しくできる。括弧を使えば計算する順番を指定できることも分かりました。
